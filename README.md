# PIT II — Cupcakes Gourmet

Projeto acadêmico de Lucas Seara Santos — RGM 34112324.

Aplicação responsiva para venda online de cupcakes gourmet, desenvolvida como continuidade da PIT I.

## Funcionalidades
- Catálogo de cupcakes.
- Carrinho de compras.
- Cálculo automático do total.
- Cadastro de nome, telefone e endereço.
- Validação de campos obrigatórios.
- Registro de pedidos em banco SQLite.
- Mensagem de confirmação do pedido.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Python
- Flask
- SQLite

## Como executar
1. Instale Python 3.
2. Instale as dependências com `pip install -r requirements.txt`.
3. Execute `python app.py`.
4. Abra `http://127.0.0.1:5000` no navegador.

## Estrutura
- `app.py`: back-end e persistência dos pedidos.
- `templates/index.html`: interface principal.
- `static/style.css`: estilos responsivos.
- `static/app.js`: carrinho, validações e envio do pedido.
- `DOCUMENTACAO.md`: documentação acadêmica e técnica.

## Observação
O projeto foi estruturado para demonstrar uma solução funcional compatível com os requisitos definidos na PIT I e com as orientações da PIT II.
